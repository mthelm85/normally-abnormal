# Normally Abnormal

*Why Real-World Data So Rarely Follow a Bell Curve*: an essay series by Matt Helm.

**Read it at [mthelm85.github.io/normally-abnormal](https://mthelm85.github.io/normally-abnormal/).**

When someone asks for "the average," they usually want to know what's typical. That
works when data follow a bell curve, but most of the things we measure don't. Each
essay takes one kind of real-world data, shows where the average goes wrong, and
offers a better way to describe it.

1. **The Average Millionaire**: why we ask for the average, where it makes sense to use it, and the fine print.
2. **A Lopsided Victory**: how skew pulls the mean away from the typical case.
3. **Ruled by the Few** *(coming soon)*: how a handful of extreme cases set the mean.

The charts use public data from the Federal Reserve, the Bureau of Labor Statistics,
the Census Bureau and the U.S. Forest Service, plus a few simulations, prepared in
Julia. The site is built with SvelteKit.
